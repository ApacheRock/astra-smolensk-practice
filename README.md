
#Автоматизация аудита безопасности в Astra Linux SE "Смоленск"
Практический кейс по администрированию российской защищенной ОС Astra Linux Special Edition "Смоленск".

##Описание проекта
В рамках проекта разработан Bash-скрипт для автоматизированного сбора метрик безопасности системы, анализа стандартных прав доступа (POSIX) и проверки механизмов мандатной защиты PARSEC. 

Проект демонстрирует навыки автоматизации рутинных задач сисадмина, работы с правами, текстовыми фильтрами и понимание специфики СЗИ (Средств защиты информации) Astra Linux.

## Реализованный функционал Скрипт `audit.sh`:
1. **Дискреционный аудит**: Скрипт проверяет права доступа на критически важный конфигурационный файл `/etc/passwd`. Наличие маски `-rw-r--r--` подтверждает, что рядовые пользователи не имеют прав на изменение учетных записей.
2. **Анализ логов**: Реализован алгоритм проверки наличия и парсинга системных журналов (`/var/log/messages`). В случае отсутствия файлов скрипт корректно обрабатывает исключение (обход падения скрипта).
3. **Мандатный аудит (PARSEC)**: Интегрирован вызов утилиты `pdp-id` с повышенными привилегиями (`sudo`) для фиксации мандатных атрибутов текущей сессии.

##Разбор результатов (Специфика Astra Linux)
В ходе тестов зафиксирован **Уровень целостности: 63 (Высокий)**. 
Для работодателя это показатель того, что:
* Сессия запущена в доверенном (административном) контексте безопасности.
* В системе активно СЗИ общего назначения, изолирующее системные процессы от потенциально вредоносного софта с низким уровнем целостности (например, браузеров).
* Продемонстрирована практическая работа механизмов защиты от перебора паролей (блокировка `pam_faillock/pam_tally2`), встроенных по треб.м ФСТЭК.
